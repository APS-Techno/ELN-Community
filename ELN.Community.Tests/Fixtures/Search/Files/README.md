# Search file fixtures

- `cyrillic-2pages.pdf`: two pages, one Russian sentence per page, DejaVu Sans embedded.
- `encrypted.pdf`: the same document, AES-256, user password `secret`, owner password `owner`.

Generated by `tools/search-reference/make_pdf_fixtures.py` in a temporary virtual environment.
Tool versions used: Python 3.13.12, fpdf2 2.8.9, pypdf 6.21.4, cryptography 50.0.2, matplotlib 3.11.2 (supplies DejaVuSans.ttf).

```powershell
python -m venv $env:TEMP\pdfvenv
& $env:TEMP\pdfvenv\Scripts\python.exe -m pip install fpdf2 pypdf cryptography matplotlib
& $env:TEMP\pdfvenv\Scripts\python.exe tools\search-reference\make_pdf_fixtures.py
```

The output differs slightly on each run because of encryption salt. Do not regenerate unless a test needs a change.
