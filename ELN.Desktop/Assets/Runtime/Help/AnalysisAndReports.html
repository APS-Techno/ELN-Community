Analysis and reports

Plot conditions against results

  1. Open a notebook and select the project and folder that contain the procedures.
  2. Choose Tools > Analysis....
  3. Select the condition value type under X Axis and the result value type under Y Axis.
  4. Check the procedures to include. Use All or None to change the selection.
  5. Click Plot. Use Copy Data (CSV) for the plotted data or Copy Chart for the chart image.

Each point represents one selected procedure. X is the first matching Condition recorded directly on the procedure. Y is the arithmetic mean of matching Results on direct child actions, actions below child specimens, and one further action level below those specimen actions. Other deeper arrangements are not included. A procedure without either required quantity is omitted.

The plot adds a linear regression when there are enough usable points. It does not establish causation or calculate uncertainty from recorded tolerances. Check the participating records and units before you interpret the line.

Chart labels can be small in the current chart and copied image. Check the copied CSV and source values when a label is difficult to read. A small label does not change the stored numeric value.

Export a PDF report

  1. For an experiment report with descendants, select its Procedure root in the item tree. Selecting a Specimen or Action offers only that single item, not its children.
  2. Choose File > Export Report....
  3. Check Items to include. The checklist is limited by the selected root. Select the required Sections: Metadata, Protocols, Values, Files, Tags, Comments and Signatures.
  4. Select A4 or Letter, then set Output path with Browse....
  5. Click Preview and inspect the report. Click Export PDF to create the PDF.

The HTML viewer plugin must be available for report preview and PDF output. The Values section includes numeric values and their recorded tolerances. Inspect rounding, page breaks and small text in the PDF before you use it. A PDF is a readable report, not an editable notebook backup.

Export a scientific package

  1. Select the project and folder. Choose File > Export... for the scientific package.
  2. Check Items to export and set Export path.
  3. Choose Include files and Include status history as required.
  4. Click Export. Read the completion message.

The package is a JSON scientific export. It records selected item trees, protocol data and referenced protocol templates. Value and tolerance fields are exported as numbers, without replacing tolerance with a display string. Deleted descendants are excluded.

Include files includes file metadata, not the attachment bytes. A scientific package is not a full notebook backup. Keep the notebook and its attachment directory together; see notebook storage.

Import a scientific package

  1. Select the destination project and folder in the open notebook.
  2. Choose File > Import scientific package....
  3. Use Browse... to select the package. Read Package preview.
  4. Click Import. Read the imported item and template counts, then inspect the destination records.

The current importer restores top-level item metadata, protocol entries and protocol templates. It does not restore exported child hierarchies, value rows, tolerances, file records or attachment bytes. Do not use it for a complete scientific round trip or recovery.

Imported protocols always start as Draft. Packaged history can be retained as history, but does not grant current approval. Imported history uses the local importing scientist and import time. Review imported protocols locally before approval.
