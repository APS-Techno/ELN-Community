Getting started

APS ELN Community is a local, single-user laboratory notebook. It stores scientific records in a SQLite database and attachment bytes in a separate directory. There is no server login or team-account administration.

Before you start

  • Use a prepared Community Desktop runtime with the scientific catalogs, selected viewer plugins and their local assets. A source build alone is not a standalone installer.
  • Choose a writable database location and a separate attachment directory. Use short local paths. Do not use a laboratory notebook to test an unfamiliar build.
  • Keep a signing password for your local profile. It is used when signing records; it does not encrypt the database or protect opening the notebook.

Create your first notebook

  1. Choose File → New Notebook.... Select a new database filename, such as notebook.sqlite. Do not select an existing file.
  2. Select a separate, empty attachment directory. The database must be outside this directory.
  3. Enter your first name, last name, signing password and matching confirmation. Complete the dialog.
  4. The application checks the seven required scientific catalogs and imports the reference data. The supplied equipment catalogs are empty; add your own equipment through Reference Data → Equipment....
  5. Select Project → New Project and complete the project dialog. Select the project before creating folders or scientific records.
  6. Create a procedure, specimen or action with the Item menu. Add a value, protocol, note or file to the selected record. See items and values.

If you select an existing filename in New Notebook, Community shows a warning and stops before asking for an attachment directory or profile. The existing file is not changed. Use File → Open Notebook... to open it, or select a different filename to create a new notebook.

Use the main window

The project panel selects a project or folder. The item tree shows its scientific hierarchy and attached content. The content panel displays the selected file, protocol, values or hypothesis view. The status bar identifies the active notebook and selected attachment. Commands that need a notebook are unavailable until one is open.

Use Tools → Dashboard for the notebook overview. Use each panel's search field to filter it; use Tools → Search... for a wider search. See search and navigation.

Set the display and paths

Open Tools → Preferences.... General settings control the VCL theme, dashboard, chart appearance, preview scope and item IDs. Tree settings control scale, spacing, tint and colors. Path settings select templates, plugins and a report logo. The attachment root is shown for information; this dialog does not move notebook files. A plugin-directory change takes effect on the next launch. An explicit --plugins launch argument selects the plugin directory for that run.

Finish safely

Save editor changes before closing or switching notebooks. Closing can ask you to save an attachment working copy. No keeps the draft in the working directory; it does not save those bytes into the notebook. Read and retain the working-copy path shown at close. See notebook backup and working drafts.
