Community Help contents

This manual covers the current single-user Community desktop and local MCP host. All pages work offline. Use the topic links below or start with Getting started.

Community uses one local identity, a SQLite database and a separate attachment directory. It does not include server login, team administration or remote storage. Local human scientific review remains available in the desktop.

A safe first workflow

  1. Create a new synthetic notebook with a separate empty attachment directory.
  2. Create a project and a procedure or specimen. Add a value with its units and tolerance.
  3. Attach a file or note, complete a protocol, and follow the local review workflow when needed.
  4. Save edits, inspect a report, then close and back up the database and attachment directory together.

A signing password does not encrypt the notebook. Scientific package exports are not complete backups. Preserve retained working drafts and recovery files before changing or restoring notebook storage.

Instructions describe existing commands; they do not grant public release or binary redistribution rights. The current proof is Win32 Debug. Other platforms, live server deployment, long-path and high-DPI behavior have separate limits.
