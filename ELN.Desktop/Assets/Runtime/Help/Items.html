Items

Items hold the scientific record in a project and folder. Open a notebook and select an active project before you create an item. An archived project does not permit scientific changes.

Understand the hierarchy

RecordUse
ProcedureThe top-level experimental procedure. The internal level is Proc. Experiment templates also use this level for an experiment root.
SpecimenA specimen within a procedure, with its own title, description and properties.
ActionA preparation, measurement or analysis step. It can be below a procedure, specimen or another action.

A protocol, note or file is attached to an item. It is not a new procedure or action. Scientific conditions and results belong to procedure and action records.

Create a procedure, specimen or action

  1. Select the destination project and folder in the project tree.
  2. Choose Item > New Procedure to create a top-level procedure. For a specimen, select its procedure and choose Item > New Specimen. For an action, select the intended parent and choose Item > New Action.
  3. Enter a Title and Description. Select the item type. For a procedure or action, select the applicable Action type and Equipment.
  4. For a procedure or action, add properties when needed and use Add Value to record conditions or results.
  5. Click Save. Check the parent and title in the item tree.

The current new-specimen path does not retain properties entered before its first Save. Create and save the specimen first, then select it and use Item > Edit to enter and save its properties.

The New toolbar menu offers creation choices for the current selection. Selecting an attached file or protocol uses its parent item. Check the resulting tree location after creation.

Edit and reuse records

Select an item and choose Item > Edit. Change the required fields and click Save. Use Item > Duplicate for a copy; select the destination and the option to link to the original when appropriate. Use experiment templates when you need a repeatable hierarchy.

The item context menu has Move to.... Dragging onto or between ordinary procedure, specimen or action rows can make the dragged record a child of the target; it is not a safe way to reorder siblings. Check the hierarchy after any drag. For top-level manual order, use Move Up or Move Down, or Ctrl+↑/↓ with the root item selected. These order commands do not reorder child records, files or values.

Add the scientific record

  • Values: use Item > Add Value on a procedure or action.
  • Protocols: use Item > Add Protocol.
  • Files and notes: use Item > Add File or Item > Add Note.
  • Tags and links: connect related records without moving them.
  • Hypotheses: connect runs and evidence to a proposal.

Delete safely

Select the correct record before you use Item > Delete. Read the confirmation. Signed records are locked, and hypothesis references can prevent unsafe deletion. Use Tools > Recycle Bin... to inspect deleted items rather than treating deletion as a backup method.
