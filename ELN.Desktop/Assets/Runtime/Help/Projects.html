Projects

Open a notebook first. The left panel contains projects, project groups, folders and Favorites. Select a project or folder to show its items in the middle panel. Groups organize projects; they do not contain scientific records directly.

Create and edit a project

  1. Choose Project > New Project.
  2. Enter the title and Description. Click Save, or Cancel to leave without creating the project.
  3. Select the project. Choose Project > Edit, or double-click it, to change its title or description.

Project edits also show the Archived check box. Save the dialog to apply the change. A project title is not a reason to rename its storage files manually.

Groups and folders

  • Choose Project > New Group. Enter Group name:. A blank name creates nothing.
  • Right-click a group to create a New Project... inside that group. To rename the group, use Rename... in its context menu.
  • Drag a project onto a group to place it in that group. The project keeps its items.
  • Select a project and choose New Folder to create a top-level folder. Select a folder first to create a subfolder. Enter the title and description, then click Save.
  • Select a folder and use Edit, or double-click it, to change its title and description.
  • Move Folder Up moves a nested folder one level toward the project. A folder already at the top level cannot move up.
  • Use the context-menu Sort commands to change sibling order: Move Up, Move Down, By Name or By Date Created.

A project folder is different from a folder item in the item tree. See Items for the record hierarchy.

Archive and reopen

  1. Select a project and choose Archive. This changes its archive state; it does not delete its records or attachment bytes.
  2. Use Show Archived in the project panel to include archived projects in the tree.
  3. Select the archived project and use Archive again to return it to active use. You can also clear Archived in the project edit dialog and click Save.

Archived projects remain readable, but scientific content changes are blocked. Restore the project to active use before editing its items or attachments. A signature can still block an edit after the project is active.

Delete containers and restore records

Project deletion is permanent. Only an empty project can be deleted. Empty folders can also be deleted. Contents in the Recycle Bin still count: remove or restore them before deleting their project or folder. Do not empty the bin only to make a container easier to delete.

Delete Group does not delete its projects. The confirmation states that its projects move back to the top level. Groups and project folders do not use item restore.

  1. To remove an item tree, select the item in the middle panel and click Delete. Confirm Move item … to the recycle bin? The item and its descendants leave the active tree.
  2. Open Tools > Recycle Bin.... Select the deleted record and click Restore. Close the dialog to refresh the project view.
  3. To remove a binned record permanently, select it and click Delete. Empty Bin requests permanent deletion of all binned records.

Permanent deletion cannot be undone. A hypothesis in review or accepted can protect a cited record from deletion. Read any refusal or kept-item message: Empty Bin can retain protected item trees while deleting unrelated ones. Signed content also has deletion guards. Attachment-only deletion is not an item recycle operation.

Use Refresh if a tree is stale, and clear panel filters if expected records are hidden. See Search and navigation, Files and notes, Integrity and Wiki.
