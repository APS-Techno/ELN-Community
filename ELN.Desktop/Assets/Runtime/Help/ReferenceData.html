Reference data

Reference data supplies the vocabulary for actions, equipment, attachments and values. Open a notebook, then use Reference Data. These are notebook-wide definitions, not the records of one selected project.

The seven scientific seed catalogs

A new notebook imports the seven shipped CSV catalogs automatically. Opening an existing notebook does not repeat this import. The catalogs and their editing routes are:

Seed catalogPurpose and editor
EquipmentTypes.csvInstrument categories. Equipment Types... edits Type and Description.
ValueTypes.csvScientific quantity definitions. Value Types... edits Symbol, Title, Units, Category, Description and the plausible range (Range min, Range max).
FileTypes.csvAttachment extension definitions. File Types... edits Extension and Description.
Equipment.csvIndividual equipment records. Equipment... edits them.
ActionTypes.csvAction vocabulary. Action Types... edits Title, Kind, Item Type, Equipment Type and Description.
FileTypeLinks.csvAllowed file types for an action type. Edit the File Types check list in Action Types....
ActionTypeEquipment.csvEquipment assignments to action types. Edit Equipment in Action Types....

The shipped Equipment catalog and action-to-equipment assignments are empty by design. A new notebook has equipment categories, but no owned instruments. The scientist adds or imports their own equipment. An empty Equipment editor is not a failed setup.

Default link types, file-type icons and templates are initialized separately. Tags..., Protocol Templates... and Experiment Templates... are additional Reference Data commands, not additional members of the seven CSV catalogs.

Add or edit a definition

  1. Open the required editor from Reference Data.
  2. Select an existing row to edit it. Use the database navigator's insert control to add a row, then complete its fields.
  3. Use the navigator's post control to finish the edit. Use its cancel control to cancel the pending row edit.
  4. Close the editor when finished. The bottom close button is not a notebook-wide Save or rollback operation.

These editors bind directly to notebook datasets. Post edits deliberately. Do not treat Close as a way to undo changes that were already posted. Delete controls remove definitions, not item records; some editors refuse deletion when a definition is in use. Read the message instead of changing scientific records only to force deletion.

Reader mappings

In Value Types..., click Reader mappings.... Select a row to edit it, or click New mapping. Enter the reader ID, key name, expected reader unit, target value type, conversion factor, and optional description label. Click Save mapping to store the rule.

A key can be a pattern. A pattern contains fixed text and the placeholders <Material> and <Any>. <Material> captures a material name, and the captured name becomes the description label. If a pattern contains <Material> two times, both must capture the same name. <Any> matches any text. The default rules include <Material> Thickness and <Material> Roughness for X-Ray Calc results, and Layer <Material>.<Any>, Parameters.<Any> and Deposition Conditions.<Any> for recipes: each recipe parameter in these groups maps by its unit, for every material and parameter name. Exact rules override patterns. If two patterns match, the pattern with more fixed text is used. Units are case-sensitive and must match the reader output. A value type referenced by a mapping cannot be deleted until the mapping is changed or removed. Deleting or editing a mapping does not alter previously extracted values.

Equipment owned by the scientist

  1. Check Equipment Types... and add the needed category first.
  2. Open Equipment... and insert a row.
  3. Enter Model, Manufacturer, Location and Description. Select its Type. Booking URL and Info URL are optional metadata fields; the notebook does not create a booking service.
  4. Post the row. Open Action Types..., select the relevant action type, choose its Equipment Type, then select the owned instrument in Equipment.

The action editor filters equipment by the chosen equipment type. Its equipment selector can be disabled when no matching instruments exist. Add owned equipment first; do not invent a placeholder instrument to fill the selector.

You can also create an action type or an instrument with the + buttons next to Action type and Equipment in the procedure/action dialog. Add Action Type requires a Title and a Kind. Add Equipment requires Model, Manufacturer and Location. OK stays disabled while a required field is empty. Use the full reference editor for the other metadata. See Create a procedure, specimen or action.

Load owned equipment from CSV

  1. Make a local CSV file with this column order: EquipmentType,Model,Manufacturer,Location,BookingUrl,InfoUrl,Description.
  2. Use existing equipment-type names in the first column. The equipment importer matches them without case sensitivity; an unknown name does not create a type.
  3. Open Reference Data > Equipment..., click Load CSV, and select the file.
  4. Inspect the imported rows and type assignments before using them in actions.

Load CSV appends rows. It is not a deduplicating merge, a preview or an all-or-nothing restore. Repeating an import can create duplicate equipment. Back up the notebook before a bulk import. The loader uses semicolons if the first line contains one; otherwise it uses commas. Use a header and one record per line. At least the first three equipment columns must be present.

Other reference editors also inherit Load CSV, but their row formats differ. The seven-file new-notebook importer and an individual editor's CSV loader are different operations. A shipped seed file is not automatically the correct input format for every editor.

File, value, action and link types

  • File Types...: register the extension used by an attachment. This supplies metadata; it does not install a viewer plugin. In Action Types..., use Filter by extension... to find file types, then check the ones associated with that action type.
  • Value Types...: select the quantity, unit and category used for recorded conditions or results. The unit can be empty for a quantity without a unit, for example Cycles. Category controls include Add, Rename and Move. Changing a unit label does not convert previously recorded numbers. Range min and Range max set the plausible range in the unit of the type; leave a field empty for no limit. The minimum must not be larger than the maximum. A value outside the range needs confirmation when you enter it. Tolerance factor (all types) sets how many times smaller than its value a tolerance can be before it needs confirmation; it must be greater than 1, and the default is 1000. Click Save beside it to store it. Existing values do not change. See Values.
  • Action Types...: choose the action's Kind and Item Type, then its equipment category, equipment and file types. Kind classifies the scientific action; it is not the item's hierarchy level. These choices control later selection lists; they do not run an instrument.
  • Link Types...: define Forward, Reverse, Description and Sort order. Forward and reverse phrases describe the same directed relationship from opposite ends.

Reference changes affect shared vocabulary in this notebook. They are not a way to unlock signed records or bypass an archived project's write restrictions. Keep scientific meanings stable when existing records use a definition.
