Series

A series is a plan for depositions that you compare, for example one deposition at 100 W, 200 W and 300 W. The plan lists the points. Each point becomes one deposition. The series view reads the values stored on each deposition and on its measurements. It shows them in one table and one plot. Open a notebook, select a project and choose Project > Series....

Plan a series

  1. Click New series....
  2. Enter Title and Purpose - what this series tests. Pick the Target folder where the depositions of this series will be made.
  3. Under Factors, click Add... for each parameter that you vary. You can use one or two factors. Select a Category, then a Value type in that category; (All) shows every type. Type a Label that says which parameter it is, for example Mo layer for the deposition time of the Mo layer. The label is optional, but a value type such as Time or Power alone does not say what it applies to. A range minimum and maximum are optional; a point outside the range is refused.
  4. With one factor, type its levels in the Levels box, separated by semicolons, for example 100; 200; 300. Each level is one point. With two factors, type the levels of each factor; Fill grid makes every combination as a point.
  5. Under Fixed conditions, click Add... for each parameter that you hold constant. Select its category and value type, type an optional label, then enter its value and an optional tolerance.
  6. Under Responses, click Add... for each result that you will measure on every point. Select its value type and type an optional label, for example Total stack.
  7. Click OK. If the plan has a mistake, the ELN says what is wrong and keeps your entries in the dialog.

The plan lists show the label in the Label column. The levels box, the Add point dialog and the table headers show the label in brackets after the value type, for example Time (Mo layer), s. A label only names the entry: the table still finds the values by their value type.

Numbers accept a point as the decimal mark, and also the decimal mark of your Windows settings. A number without a unit is in the unit of its value type, which the field name shows, for example Value, Pa. You can also type a number with another unit of the same kind, for example 2 mTorr for a value type in Pa. This works for ranges, fixed values, tolerances, levels and Add point. The ELN converts the number and stores it in the unit of the value type; the entry dialog shows the converted number below the fields. A unit that the ELN does not know, or a unit of another kind, is refused. A tolerance cannot use a unit with an offset, such as °C for a value type in K.

Select the series in the list at the left. The list shows its status and its progress, for example 2/5 measured.

A new series is Active at once. A series that an assistant made through MCP stays Draft until you click Start; a Draft series accepts plan changes but no depositions. Edit plan... changes the title, purpose, folder, labels, ranges, fixed conditions and responses. While the series has points, you cannot add, remove or change factors: remove all points to change them. Edit... on a factor still changes its label. Close marks the work as done; only the author can close or reopen a series. Abandon... keeps the series in the list as Abandoned. A closed or abandoned series does not change.

Make or link depositions

The table has one row for each point, from the start. A row without a deposition is planned. Right-click a row to see what you can do with it; double-click a planned row to make its deposition.

  • Make deposition... (planned row): opens the new procedure dialog with a title that holds the series title and the levels, the type Synthesis, and the action type and equipment of the last deposition in the series. The dialog has no Values tab. Click OK to make the deposition in the target folder. The ELN writes each level and each fixed condition as a condition value with the mark planned. The description of each value is the label of its plan entry, or Planned value from series <title> when the entry has no label. Add other values on the deposition after it is made.
  • Link existing deposition... (planned row): pick a deposition that you made before. It must be a top-level item of the same project. Use this for depositions made before the plan.
  • Open deposition (row with a deposition): goes to the item.
  • Mark failed...: use it when the attempt did not work. Enter a reason. The point returns to planned, and Make deposition... makes the next attempt. Click Show failed to see failed attempts in the table.
  • Unlink deposition: takes the deposition out of the point. The deposition stays in the notebook.
  • Remove point (planned row): removes the point from the plan. A point with a deposition cannot be removed; unlink the deposition first.

If the status line reports depositions in the recycle bin or another project, those depositions are left out of the table; Unlink excluded takes them out of the series.

Link from the item tree

Right-click one top-level item, or select several, and choose Link to plan point.... The dialog lists the Active series of the project. For the series that you choose, the list shows what will happen to each item: item → 200 W (the item goes to the free point with that level), item → new point 250 W (no point matches), or the reason why the item cannot be linked, for example no Power value.

The ELN matches an item by the factor values stored on it and on its children, within the tolerance of the stored value. It uses only the first free point that matches. Tick Add new points for depositions that match no point to add those levels to the plan as added points; the range of the plan still applies. For one item you can also choose the free point by hand in Plan point. Click Link to apply the list. The series view opens.

When an item sits in a series, the detail panel shows a line such as Series: Ti rate (200 W); a failed attempt has , failed after the levels. Confirm planned values in the item menu confirms the planned values of the item, as in the series table. A signed item cannot be confirmed.

Confirm planned values

A planned value is the value from the plan, not a measured value. The table shows it in grey italic with the text planned. The plot does not use it, and the export leaves its field empty. A planned row shows its level in grey.

When the deposition went as planned, right-click its row and choose Confirm planned values. One click confirms all planned values of the deposition. If the real value was different, edit the value on the deposition; this also removes the planned mark. A signed deposition cannot be confirmed.

When the stored value of a factor differs from the level of its point, or a fixed condition differs from the plan by more than the tolerance, the cell shows a warning sign. Point at it to read Differs from the plan (planned value). With no plan tolerance, the ELN compares with the tolerance of the stored value; with neither, it needs an exact match.

Add points

Click Add point... to add a point to the plan. Enter one level for each factor and, if you like, a reason. On an Active series the ELN then opens the new procedure dialog for the deposition of that point, the same as Make deposition...; click OK to make it. If you cancel, the point stays in the table as planned, and you can make or link its deposition later or remove the point. On a Draft series, Add point... only adds the point. A point added to an Active series is marked added in the Point column. A level that is already in the plan, or outside the range, is refused.

Read the table

The Table tab has these columns:

  • Point: the levels with their units. Rows are in the order of the first factor, then the second. Point at a Point or State cell to see the deposition.
  • State: planned (no deposition), deposited (a deposition, but a response is missing), measured (all responses present) or failed. A planned value never counts as a present response.
  • The data columns. Condition columns show values entered as conditions; result columns show measured results. A value that sits on a measurement below the deposition (for example an XRR measurement) has its own column, named with the measurement method. The ELN never averages values from different methods.
  • value ± tol: the value and its tolerance.
  • —: the deposition has no such value.
  • Several values with a warning sign: the same method gave more than one value, for example two specimens. The ELN shows all of them and does not choose one. These cells are not plotted.

Right-click a column header to set its role: Shown, Hidden, Varied or Response. Hidden columns stay in the table in grey, but not in the plot or the export. Roles are saved with the series. Double-click a cell to open the item that holds the value.

Plot

Open the Plot tab.

  1. Choose X (condition). The default is the first Varied column.
  2. Tick one or more result columns under Y (results). The default is every Response column.
  3. Optional: choose Group by (condition) to draw one curve for each value of a second condition. The plot shows the first 8 groups. With grouping, the plot uses the first ticked result column.
  4. Optional: tick Linear trend. It works when one curve is visible.

Vertical error bars show the tolerance of each result value. Only rows with a deposition are plotted. Rows with a missing or ambiguous value are not plotted. Planned values are not plotted; the plot says n point(s) wait for confirmed values. when a deposition still holds planned values in the columns that you plot.

Export to Origin

  • Copy table puts the table on the clipboard as tab-separated text. Paste it into an Origin worksheet.
  • Save CSV... writes the same table as a comma-separated file with a point as the decimal mark.

Row 1 holds the column names and row 2 holds the units. A tolerance goes into its own column named with the ± sign, next to its value column. Origin can use that column for error bars. Hidden columns are not exported. Planned rows are not exported, and planned values are written as empty fields.
