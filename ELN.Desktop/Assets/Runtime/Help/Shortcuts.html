Keyboard shortcuts

Shortcuts depend on focus. This page lists the explicit bindings in the current selected Community source. The Community host does not provide the legacy desktop's F5 binding; use Refresh in the menus.

Main window

KeyAction
Ctrl + FNavigate → Search...: search notebook records.
Ctrl + GNavigate → Go to Item...
Ctrl + DNavigate → Dashboard
F1Help → Keyboard Shortcuts...: this page.

A key does nothing while its menu command is unavailable, for example before a notebook is open. In the Help window, Ctrl + F moves the focus to Search Help instead.

Item tree

KeyActionRequired selection
Ctrl + ↑Move the selected root item up in its manual order.A top-level scientific item in the focused item tree.
Ctrl + ↓Move the selected root item down in its manual order.A top-level scientific item in the focused item tree.

These keys do not move child items, attachments or values. Reordering requires a writable record and compatible manual sorting. See items and hierarchy.

Markdown editor

KeyAction
Ctrl + SSave through the host's file service. A conflict still needs an explicit decision.
Ctrl + BWrap the selected text in Markdown bold markers.
Ctrl + IWrap the selected text in Markdown italic markers.
Ctrl + KInsert a Markdown link with the selection as its label; replace the URL slot.
Ctrl + VPaste normally. If the clipboard contains an image and no text, try to upload it as an attachment and insert its Markdown reference.

The editor must have focus. Image paste needs a writable owner and host attachment support. The current handlers also accept Shift with these Ctrl combinations, but Shift does not select a separate save or formatting command. See files and editor conflicts.

Help window

KeyAction
/ or Ctrl + FMove the focus to Search Help.
↑, ↓, EnterSelect a Help search result and open its section.
EscClear the search box, or close Contents in a narrow window.
Alt + ←, Alt + →Go back or forward between Help pages.

These keys work only in the Help window. Search Help searches this manual, not notebook records.

Menu access

Use the main menu headings File, Project, Item, Navigate, Reference Data, Tools and Help. Windows menu access keys are shown by the menu underlines. Use Help → Contents... for the manual and Help → Keyboard Shortcuts... for this page. Do not assume a shortcut from the Commercial manual applies to Community.
