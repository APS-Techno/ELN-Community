Tags, comments and links

Open a notebook and select an item. Tags classify it, comments record discussion, typed links describe relationships, and Favorites provide navigation shortcuts. These functions do not move attachment bytes or replace scientific values.

Create and assign tags

  1. Right-click the item and choose Tags....
  2. Check a tag to assign it to the item. Clear its check box to remove that assignment. Changes are applied when the check box changes.
  3. To create a tag, click Add. Enter Name:, choose Color: with Choose..., then click OK.
  4. Select a tag and click Edit to change its name or color. Click Close when finished.

You can select several items and choose Tags.... The Items column shows k of N: k items of the N selected items have the tag. Check a tag to assign it to all selected items. Clear a check box to remove the tag from all selected items. Changes apply at once.

Reference Data > Tags... opens the notebook-wide Tag Editor without item-assignment check boxes. Tags appear as colored item-tree badges and their names can be found with Search.

Delete removes the selected tag definition and its item assignments, not just the tag on the current item. To remove a tag from one item only, clear that item's check box. Close is not an undo command for assignments or catalog edits.

Comments

  1. Right-click an item and choose Comments.... If comments exist, the caption includes their count.
  2. Enter nonempty text in the comment box and click Post. The list records the date, local identity and comment text.
  3. Select one of your comments and click Edit. Enter the corrected text and confirm it. You can edit only your own comments.
  4. Select a comment and click Delete. Confirm only if it must be removed. Click Close to leave the discussion.

Comments are different from rich-text notes. Deleting a comment does not put it in the item Recycle Bin.

Create a typed item relationship

  1. Right-click the intended target item and choose Copy as Link Target.
  2. Select the other item. Right-click it and choose Link to....
  3. Choose Relationship:. Read the sentence shown in the dialog to check which item is the source and which is the target. Forward and reverse wording can change the stored direction.
  4. Add optional Notes:, then click Link. Cancel creates nothing.

The link type must exist in the notebook's vocabulary. An existing relationship between the items is reported rather than duplicated. Copy as Link Target supplies the in-application target; it is not an attachment copy or a record move.

Manage and follow links

  1. Select the item and choose Item > Links..., or click Manage... in its inline Links panel.
  2. Use Add... to pick another item and choose a relationship. Use Edit... to change a selected relationship or its notes.
  3. Use Remove to delete a relationship after confirmation. The linked items remain.
  4. Select a relationship and click Open, or double-click it, to navigate to the other item. A normal inline link row also navigates; a more-rows entry opens the manager.

Relationship text is read from the current item end. An outgoing or incoming arrow helps show direction. Changing a definition in Reference Data > Link Types... changes the wording used to display its relationships. See Reference Data.

Favorites

Right-click an item and choose Add to Favorites. Once bookmarked, the same command becomes Remove from Favorites. Use the left panel's Favorites branch to return to the location. Removing a favorite removes the shortcut, not the record. Project and folder favorites also use this branch.

Signatures and read-only boundaries

The item menu separates annotations from signed-content edits. Tags, comments, Favorites and relationship tools are not a way to unlock a signed item. The Links manager permits reading and opening targets in a read-only project, but disables Add, Edit and Remove when the project is not writable. Signed content and attachment saves keep their own guards. Do not assume that every annotation is part of a signed scientific payload; see Integrity.

For links inside a Markdown body, use Wiki navigation. A Markdown reference does not create a typed relationship.
