Templates

Protocol templates define entry forms. Experiment templates define item hierarchies. They are different records. A template supplies structure, not scientific approval or evidence that an experiment was performed.

Create a protocol template

  1. Open a notebook. Choose Reference Data > Protocol Templates....
  2. Click Add. Enter Name, Description and Category. Set Active as required.
  3. In Structure, use +Section, +Row and +Field to build the form. Select each element to edit its properties. Use Up, Down and Delete to adjust the structure.
  4. Use Tags... to select relevant equipment types or devices. Use Preview to inspect the form.
  5. Click OK to save the template. Apply it with Item > Add Protocol....

Load Example... supplies an example structure in the editor. Check and replace its fields before you save your template. Do not treat example content as a completed scientific record.

Maintain protocol templates

In Template Manager, select a template and use Edit or Duplicate. Editing a template in use creates a separate version. Existing protocols retain their original schema. Show all versions (including inactive) displays older and inactive records. Deleting a template in use deactivates it instead of removing the referenced form.

Reimport loads protocol templates from the configured templates directory, or the application's ProtocolTemplates directory when none is configured. Select the categories and overwrite choice in the import dialog. Read these choices carefully; reimport is not the experiment-template file importer.

Create an experiment template

  1. Choose Reference Data > Experiment Templates....
  2. Click Add. Choose a Procedure or Item (Specimen) root in the prompt.
  3. Enter Name, Category and Description.
  4. Select a structure node. Set its Title, Level, Type and Action Type. Use Add Child and Add Sibling to build the required hierarchy. A template has one root.
  5. Click Save. Inspect the saved hierarchy before you use it.

Use Duplicate to start a separate template from an existing one. Delete removes the selected template after confirmation; it does not delete experiments already created from it.

Reuse an experiment template

  1. Select an active destination project and folder.
  2. Choose Item > New from Template....
  3. Select a template and inspect the hierarchy preview, including action types and equipment.
  4. Enter Experiment title and click Create.
  5. Inspect the created items. Complete their values, protocols and attachments with the actual scientific record.

Template application saves the complete hierarchy and its audit records together. A failed application does not leave a partially created experiment. Import and export resolve action types by name across folder, procedure and item nodes; inspect any missing-name warnings.

Import and export experiment templates

Use Export in Experiment Templates to save the selected template as .elntemplate. Use Import to read one file, or Import All... to select a folder of these files. Read the import warnings and inspect the resulting action-type mappings before use. Use trusted template files only.
