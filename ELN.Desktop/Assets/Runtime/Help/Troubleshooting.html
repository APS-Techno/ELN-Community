Troubleshooting

Preserve the database, attachments and retained drafts before attempting recovery. Resolve the reported cause; do not edit database rows, remove format markers or delete sidecars to bypass checks.

SymptomWhat to check
A command is disabled.Open a notebook and select the required project, item or attachment. Some operations are refused for archived, signed or read-only records.
New reports a missing scientific catalog.The Desktop executable needs its CSV directory with all seven selected catalogs. Obtain the matching Community runtime assets. Do not use a personal user CSV or an unrelated legacy installer tree.
New refuses an attachment directory.Select a separate empty directory. The database must be outside it. Existing files are never reused or deleted by notebook creation.
Open reports unsupported local format or identity count.Select a Community format-5 notebook with exactly one active identity. The Desktop offers to upgrade formats 2, 3 and 4; it first writes a backup beside the database. Older clients cannot open the upgraded notebook. See notebook formats and backups. Open is not a Commercial conversion or migration tool.
Open asks you to close or recover the notebook.Close its owning client and preserve the database plus its journal/WAL sidecars. Recover through the owning client; do not delete sidecars.
Attachments are missing after moving or restoring a notebook.Move the folder that contains both the database and the attachment directory as one unit. If Community reports that the saved attachment directory is missing, select the matching attachment root and let Community remember it. Restore the full directory tree together with the database. Do not manually rename stored files.
Help file not found.The executable needs Help/Index.html, Help/Shortcuts.html, all topic pages and help.css. The Community Desktop helper stages this payload after a successful build.
The HTML viewer is unavailable or Help is blank.Select the matching Community HTML viewer plugin and its shared Core prerequisites. Verify the external WebView2 runtime/loader. A plugin-directory preference change needs a restart. Keep incompatible old APS packages out of the process search path.
A viewer reports that it could not open a file.The selected reader rejected the input. Check its format and the reported reader error. A rejected file is not shown as a successful load and is not retried through a generic reader. Keep the original file unchanged.
Markdown math, protocol forms or images do not display.Check the selected viewer packages and their local assets: Plugins/MarkdownViewer/ and Plugins/Templates/. Keep browser vendor/font subdirectories intact. Relative image references also need their matching notebook attachments.
An editor reports a save conflict.Keep the draft. Cancel to avoid overwriting, Reload to use current stored bytes, or choose Save Anyway only after checking what it will replace. Signed/read-only changes can still refuse the write. See files and drafts.
A rename or upload reports recovery failure.Keep the named backup and draft paths. Stop further changes and compare stored bytes and metadata before recovery. Do not hide the error by renaming files manually.
A signing password is refused.Use the exact local signing password. Opening the notebook does not validate that password. A failed signing attempt must not be treated as a completed signature.
Equipment list is empty.This is the Community seed, not a failed import. Add your own equipment through Reference Data. See reference data.
Controls are clipped or a long file path fails.Existing high-DPI and deep-path limits remain. Enlarge the dialog if supported, use shorter local paths and retain drafts. Do not assume these limitations are fixed by this Help payload.
Small values appear as zero on chart tick labels.Check the actual scientific values and units. Current chart labeling can round very small numbers even when the stored Double series retains them. PDF value tables preserve numeric values and tolerances; see reports.
A scientific package import omits data.Package import is not a complete backup restore. The current importer supports its metadata/protocol subset; retain the original notebook and files.
MCP fails at startup or a tool is refused.Check all four absolute paths, the existing upload/plugin directories and current tool schema. Signed, foreign and missing targets remain refused. Human hypothesis gates are desktop-only.

Report a problem without exposing records

Record the command, exact error, build configuration and relevant file category. If possible, reproduce with a new synthetic notebook. Do not include passwords, keys, personal records, private endpoints or laboratory data in a public report. Keep full local evidence private until its contents are reviewed.
